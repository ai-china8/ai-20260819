一KMS 客户端激活三步

在「开始菜单」右键 → 选择 Windows PowerShell(管理员)，依次执行。三步顺序不可乱。

1
安装产品密钥（GVLK） 
slmgr /ipk <你的 GVLK>

不同系统版本的 GVLK（即 KMS 客户端安装密钥）不一样，例如 Windows 10 LTSC、Windows 10 Pro 各有固定值。
⚠️ GVLK 是微软官方公开的客户端密钥，它只告诉系统「该去哪类 KMS 激活」，本身不能独立激活，必须配合合法的 KMS 主机。 本站另有《GVLK 密钥大全》可查各版本对应值。

2
指定 KMS 主机 
slmgr /skms <你的授权 KMS 主机>

此处应填你方自建 / 组织授权的 KMS 主机名（如 kms.your-domain.local，客户端经内网 DNS _vlmcs._tcp 自动发现）。
原笔记此处写的是第三方公共地址，本页不提供——请改用你方合法主机。

3
执行激活 
slmgr /ato

需要等一会儿。激活后到「此电脑 → 属性」查看是否激活；若未成功可重启电脑再试，通常即可完成。

激活阈值：Windows 的 KMS 激活要求网络中达到 25 台已连该主机的客户端才会批量激活（Windows Server 为 5 台）。这是微软设计，与主机是否「可用」无关。

二一键 bat 脚本写法

不想一条条输入，可建一个 .bat 文件，右键「以管理员身份运行」。

原笔记的提示（保留）：bat 中命令不要直接逐行复制，有时会出错——因为需要前一条确认完成后才执行下一条。可用 && 操作符确保顺序执行。
@echo off
slmgr /ipk <GVLK> && slmgr /skms <授权 KMS 主机> && slmgr /ato

把 <GVLK> 与 <授权 KMS 主机> 换成你的合法值即可。注意直接复制网络命令可能因编码 / 换行出错，用 && 串联可避免顺序问题。

三其他常用 slmgr 命令

以下均为微软官方 slmgr 工具的合法参数，用于管理激活状态。

命令作用
slmgr /upk卸载当前产品密钥
slmgr /xpr查看激活过期时间（KMS 激活自激活日起约 180 天到期，到期前客户端会自动向主机续期）
slmgr /dlv显示详细激活信息（主机地址、剩余宽限期等）
slmgr /ckms清除指定的 KMS 主机，恢复为自动发现

四关于「KMS 服务器地址」的合规说明

原始笔记罗列了一批第三方公共 KMS 服务器（十余个地址）。本页不提供、不罗列任何第三方 KMS 主机地址，原因：

  • 法律：连接未授权 KMS 激活属于规避软件授权，组织 / 企业使用更涉合规风险。
  • 安全：公共 KMS 历史上曾被用于投递恶意软件，连入即把系统暴露给不可信第三方。
  • 稳定：这类地址随时失效、随时更换，依赖它们必然频繁激活失败。
正确做法：如需使用 KMS 激活，请通过 批量许可（VLSC） 获取 CSVLK 自建 KMS 主机；或向组织 IT 管理员索取授权的内网 KMS 主机地址（客户端经内部 DNS _vlmcs._tcp 自动发现），勿自行联网寻找来路不明的公共 KMS 服务。
