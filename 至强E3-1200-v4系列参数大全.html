一、系列概览

E3-1200 v4 是 2015 年 Q2 推出的第四代入门至强，基于与五代酷睿（Core i 5000 系桌面 Broadwell）同源的 Broadwell 内核，仍用 LGA 1150 接口。与 v3（25 款）不同，v4 是一个刻意做小、且全部面向图形/视频转码/远程工作站的家族——英特尔官方 "E3 v4 Family" 页面仅列 5 款，全系均为 Iris Pro 核显或低功耗型号，没有无核显的"主流"型号。

重要：v4 没有 "E3-1230 v4 / 1240 v4 / 1280 v4" 这类主流无核显型号！ 与 v1~v3 不同，v4 全系 8 款均为 4 核 8 线程 + 核显（仅 OEM 的 E3-1270L v4 未标注核显），且 L3 统一为 6 MB（比 v3 的 8 MB 还小）。它本质是"带最强核显的转码/远程工作站专用 U"，不是用来替代 1230 v3 当性价比游戏 U 的。若想用无核显的性价比 E3，请回到 v3（如 E3-1231 v3）。
后缀速记：带 5（1285 及 L 版）为 Iris Pro P6300（集成 128MB eDRAM，核显最强，适合转码）；8（1258L/1278L/1283L）多为 Iris Pro P6300 或 HD P5700；带 L 为低功耗版；无后缀数字 0 的 1270L 为 OEM 低功耗。全系 4C/8T（均支持超线程）。
相对 v3 的主要变化：① 制程 22nm→14nm，能效更好；② 接口仍为 LGA 1150（与 v3 同主板平台，BIOS 需含 v4 微码）；③ 核显升级为 Iris Pro P6300（带 eDRAM），转码/图形性能约为 v3 P4600 的 1.8 倍；④ L3 由 8MB 降为 6MB；⑤ PCIe 升级到 3.0；⑥ 家族大幅精简为 8 款、全部带核显。

五、平台兼容与选购建议

  • 主板芯片组：与 v3 同代平台——服务器 C224/C226（C226 支持 ECC+IPMI），消费级 H81/B85/H87/Z87/Z97 等多数可上，需 BIOS 含 v4 微码。
  • 内存：支持 DDR3L（低压 1.35V，部分板兼容标准 DDR3），双通道，最大 32 GB。注意 v4 内存控制器偏好 DDR3L。
  • 核显（本代核心卖点）：除 OEM 的 1270L 外全系带核显；1285/1284L/1283L/1265L/1278L 为 Iris Pro P6300（128MB eDRAM），转码/远程图形性能约为 v3 P4600 的 1.8 倍；1258L 为 HD P5700。
  • 指令集：支持 AVX2 / AES-NI / VT-x / VT-d / TXT；PCIe 升级到 3.0（v3 为 2.0）。
  • 封装差异：只有 LGA 1150 的 5 款可 DIY 升级；BGA-1364（1258L/1278L/1283L）已焊死在板上。
怎么选（v4 适用场景）：
• 视频转码 / 软路由 / 轻量 NAS 带显示输出 → E3-1265L v4（35W + Iris Pro P6300，能效与核显兼顾的甜点）；要更强转码选 E3-1285L v4（65W）或旗舰 E3-1285 v4（95W）。
• 远程工作站 / 多用户 3D 交付 → E3-1285 v4（Iris Pro + GVT 显卡虚拟化），一台可服务多名设计师。
• 嵌入式 / 工控 / 品牌机 → BGA 封装的 1258L/1278L/1283L v4（多为整机出厂，非零售）。
• 想要"无核显性价比游戏 U"？ v4 没有！请回到 v3 的 E3-1231 v3 / 1240 v3（4C8T、80W、无核显、配独显），或跳到 v5。
• 与 v3 同板对比：同接口，v4 核显强得多、功耗略低，但单核频率与 L3 不如 v3 高频型号——纯 CPU 性能 v3 反而略占优。
