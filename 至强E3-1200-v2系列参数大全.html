一、系列概览

E3-1200 v2 是 2012 年 Q2 推出的第二代入门至强，基于与三代酷睿（Core i 3000 系）同源的 Ivy Bridge 内核。相比 v1（Sandy Bridge），制程从 32nm 升级到 22nm，功耗明显下降、内存频率提升到 1600，核显也换为 HD Graphics P4000。

Ivy Bridge微架构（与 i7-3770 同源）
22 nm制程工艺（v1 为 32nm）
LGA 1155物理接口（同 v1 插槽）
DDR3-1600双通道，最大 32GB
69 / 77 W主流 TDP（较 v1 更省电）
AVX支持 AVX，不支持 AVX2
后缀速记（与 v1 一致）：型号带 5（1235/1245/1275）内置核显 HD Graphics P4000，可免独显亮机并支持 Quick Sync 转码；不带 5（1230/1240/1270 等）无核显，需独显；带 L 为低功耗版；数字越大频率越高。
相对 v1 的主要变化：① 制程 32nm→22nm，同频能效更高；② TDP 由 80/95W 降至 69/77W（低功耗版更降到 17/45W）；③ 内存 1333→1600 MT/s；④ 核显 P3000→P4000；⑤ 频率整体小涨约 0.1–0.2 GHz；⑥ 仍不支持 AVX2，接口仍是 LGA 1155（但需主板 BIOS 同时含 v2 微码才能点亮）。

五、平台兼容与选购建议

  • 主板芯片组：服务器用 C202/C204/C206（C206 支持 ECC 与 IPMI）；消费级 H61、B75、Q77、Z77 等多数可上，但务必确认 BIOS 已含 v2 微码（老 H61 可能需要刷 BIOS 才能识别 v2）。
  • 内存：消费板用 DDR3 非 ECC（最高 1600）；C2xx 服务器板可用 DDR3 ECC UDIMM。双通道，最大 32 GB，带宽约 25.6 GB/s。
  • 核显：仅 12x5 系列（1235/1245/1275/1265L v2）带 HD Graphics P4000，可免独显亮机与转码；其余型号必须配独显。
  • PCIe：CPU 提供 20 条 PCIe 2.0 通道（典型 ×16 显卡 + ×4 扩展）。
  • 指令集：支持 AVX / AES-NI / VT-x / VT-d / TXT，但不支持 AVX2——依赖 AVX2 的新软件会回退到较慢路径。
怎么选：
• 预算游戏/生产力主机 → E3-1230 v2 / 1240 v2 / 1270 v2（69W、4C8T、无核显，配独显最划算，比 v1 同档更省电）；
• 需要核显亮机或转码（软路由/NAS/轻量 HTPC）→ 选 12x5 v2 带核显型号（P4000 转码更强）；
• 低功耗 NAS / 7×24 开机 → E3-1265L v2（45W）或 E3-1220L v2（17W）；
• 追求最高单核 → E3-1290 v2（4.1 GHz 睿频，但 87W 且价高）；
• 避开 E3-1220 v2 / E3-1225 v2：同为 4 核却无超线程，多线程明显落后同价 1230 v2。
• v1 还是 v2？ 同接口、价格相近时优先 v2：功耗更低、内存 1600、核显更强；但 v1/v2 主板 BIOS 需分别确认微码支持。
